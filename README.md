# Electricity Demand Analysis

This project analyzes electricity demand patterns using Python, SQL, and Tableau.

---

## Overview
- Processed raw hourly electricity demand data
- Extracted time-based features (hour, month, weekday)
- Identified peak demand periods
- Visualized trends using Tableau

---

## Tools & Technologies
- Python (pandas)
- SQL
- Tableau

---

## Project Structure
- `clean_data.py` → data preprocessing
- `analysis_queries.sql` → SQL analysis
- `cleaned_energy.csv` → cleaned dataset
- `PJM_Load_hourly.csv` → raw dataset

---

## Key Insights
- Demand peaks during evening hours
- Clear daily demand pattern
- Seasonal variations present
